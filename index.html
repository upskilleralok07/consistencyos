About

Consistency OS is a lightweight personal tracker. Inside Claude, your data is stored securely and privately tied to your account. If you download this file and host it yourself (Netlify, GitHub Pages, etc.), it automatically switches to your browser's local storage on that domain — your data still persists between visits on that device/browser, but won't sync back to Claude. Export a JSON backup regularly if you move between the two.
